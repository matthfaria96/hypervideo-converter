# Phase 03.1 — UI design contract

Written by the plan-phase orchestrator, because this is an autonomous run and the gate's `--auto` chain wasn't active. The visual language is fixed: the existing redesign's tokens (`Views/Components/Theme.swift`). This contract only places the HandBrake settings inside that language.

## 1. Layout states (ContentView right column)

| Selection in the Video List | Right column | Width |
|---|---|---|
| none / several videos | **OutputInspector** (unchanged "Output Settings": scope chip, format, quality profile cards, estimate, codec/resolution/quality, toggles). Its old "Advanced Settings…" button becomes a hint card: icon `slider.horizontal.3`, "All HandBrake settings" / "Select one video to see every setting: dimensions, filters, video, audio, subtitles, chapters and tags." With ≥1 video in the list it has a button "Show Settings of First Video" that selects the first video. | 310 pt |
| exactly one video, info loaded | **VideoSettingsPanel** (new) | 460 pt (animated `.smooth(duration: 0.2)`) |
| exactly one video, still loading / error | VideoSettingsPanel header + a `ProgressView` or the error text | 460 pt |

The workspace column keeps `minWidth: 0` and takes what is left. The window's minimum width rises so the workspace keeps at least 420 pt when the sidebar is expanded: 220 + 420 + 460 + separators ≈ 1,102 pt. Set `.frame(minWidth: 1100, minHeight: 640)` on the window content (check the current minimum and raise it only if needed).

## 2. VideoSettingsPanel anatomy (top → bottom)

1. **Header** (padding 18, background `Theme.inspector`): 44 pt thumbnail (`Thumbnail`), file name (13 pt semibold, middle truncation), preset name (10 pt `Theme.muted`), and on the trailing side a ghost button `xmark` "Close" (help: "Back to the settings for all videos"). It clears the selection.
2. **Tab bar**: a custom `SettingsTabBar` with 8 equal-width buttons in one row: icon (13 pt SF Symbol) over a 9 pt label. The selected tab has a `Theme.accentWash` fill, a `Theme.accentLight` icon/label and a 2 pt `Theme.accent` underline. Others use `Theme.muted` with a hover `Theme.panelRaised`. Order and symbols:
   - Summary `doc.text.magnifyingglass`
   - Dimensions `crop`
   - Filters `camera.filters`
   - Video `film`
   - Audio `waveform`
   - Subtitles `captions.bubble`
   - Chapters `list.bullet.indent`
   - Tags `tag`

   Each button has `.help(title)` and `.accessibilityLabel(title)`. The tab binds to `model.ui.detailTab` (`SettingsTab`), and ⌘1…⌘8 switch tabs while the panel is shown.
3. **Validation banner**: `StatusBanner` with `settings.validationIssues` when there are any.
4. **Scrollable tab content** (padding 16, spacing 12). Sections use `SettingsSection` (12 pt radius card, `Theme.panel`).
5. **Footer** (padding 14, top hairline `Theme.separator`): "Apply to All Videos" (subtle, only when the list has more than one video, with the existing confirmation dialog) · Spacer · "Save as Preset…" (subtle, existing save-preset flow).

### Compact rows

`SettingRow` gets a `labelWidth` (default 170, unchanged for the sheet). Inside the panel it's 128, set through an environment value `settingsLabelWidth`. Help text stays at caption size under the label. Segmented pickers that don't fit become menus (`ViewThatFits`).

## 4. Tokens and type

- Background `Theme.inspector`, cards `Theme.panel`, hairlines `Theme.line`, text `Theme.text`, secondary text `Theme.muted`, accent `Theme.accent` / `Theme.accentLight` / `Theme.accentWash`.
- Section titles 13 pt semibold muted, row labels 12 pt, help 10–11 pt caption, numbers `.monospacedDigit()`.
- Controls: native `Picker` (menu or segmented), `Toggle(.switch)` with `.controlSize(.small)`, `Slider` with `.tint(Theme.accent)`.
- Always dark (`.environment(\.colorScheme, .dark)` is already applied at the window level).

## 5. Copy and localisation

Every new string is a `LocalizedStringKey` in English with a pt-BR entry in `Resources/pt-BR.lproj/Localizable.strings`. Model display names come from the core through `Text(localizing:)` and also need pt-BR entries. HandBrake's own pt-BR wording (from `HandBrake.app/Contents/Resources/pt_BR.lproj`) is the preferred translation where one exists, for example "Taxa de quadros", "Recorte", "Bordas", "Mixagem", "Taxa de amostragem", "Ganho", "Marcadores de capítulo".

## 6. Accessibility

- The tab bar buttons are buttons with labels and selected traits.
- Every icon-only button has `.help` and `.accessibilityLabel`.
- Track rows combine their children.

## 7. Advanced sheet

Keep `AdvancedSettingsSheet` as the ⌘E "open in a large window" path, reusing the same tab content views. Its `SettingsTab` enum gains filters, chapters and tags. Trim moves into Summary.
