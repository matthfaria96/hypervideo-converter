## Pattern Assignments

### Lenient model decoding (`EncodeSettings.swift`, `VideoFilters.swift`, every new Codable type)

**Analog:** `Core/Models/EncodeSettings.swift` lines 235-270.
```swift
extension EncodeSettings {
    private enum CodingKeys: String, CodingKey {
        case container, videoCodec, rateControl, ... , trim, optimizeForWeb, keepMetadata   // add new keys here
    }
    public init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        let d = EncodeSettings()
        container = try c.decodeIfPresent(ContainerFormat.self, forKey: .container) ?? d.container
        extraAudio = try c.decodeIfPresent(AudioEncoding.self, forKey: .extraAudio)   // optional: no default
        trim = try c.decodeIfPresent(TrimRange.self, forKey: .trim)
    }
}
```
Rule: defaulted field -> `?? d.field`; optional field -> bare `decodeIfPresent`. Add every new field to `CodingKeys` AND the init (encoding stays synthesized). The init body is long: split the new keys into a second helper or a nested Codable struct (e.g. `video: VideoEncoderOptions`) to keep functions < 50 lines (D-09). `VideoFilters.init(from:)` uses the same shape with literal defaults:
```swift
deinterlace = try c.decodeIfPresent(DeinterlaceMode.self, forKey: .deinterlace) ?? .auto
denoise = try c.decodeIfPresent(FilterStrength.self, forKey: .denoise) ?? .off
```
Enums: `String, Codable, CaseIterable, Identifiable, Sendable` with `id`, `displayName` switch returning English literals (the pt-BR key), as `DeinterlaceMode` (VideoFilters.swift 3-18). `FilterStrength` currently `off/light/medium/strong`; per FIL-06 keep those raw values and add `ultralight`, `stronger`, `verystrong` so old JSON still decodes. Keep `.amount` semantic used by `FrameFilter`.

### `FrameFilter.swift` Core Image filters

**Analog:** itself. Each filter is `static func name(_ image: CIImage, ...) -> CIImage`, uses `CIFilter.<builtin>()`, `clampedToExtent()` on input, and `.cropped(to: image.extent)` on output with `?? image` fallback:
```swift
static func denoise(_ image: CIImage, amount: Double) -> CIImage {
    let filter = CIFilter.noiseReduction()
    filter.inputImage = image.clampedToExtent()
    filter.noiseLevel = Float(0.01 + 0.03 * amount); filter.sharpness = 0.4
    return (filter.outputImage ?? image).cropped(to: image.extent)
}
```
`render(_:sourceSize:plan:filters:deinterlace:overlay:)` applies, in order: deinterlace -> denoise -> sharpen -> grayscale, then geometry transform composited over `CIImage(color: .black).cropped(to: output)`, then overlay. New filters (bob, hqdn3d/nlmeans tunes, chroma smooth, unsharp/lapsharp, colorspace, padding colour via the canvas colour replacing `.black`) slot into that chain and each get their own `static func` testable in isolation. Put new ones in `FrameFilter+Denoise.swift`/`+Sharpen.swift` to stay < 400 lines. `render` already has 5+ parameters: pass a single `VideoFilters` + a small plan struct instead of adding more.

## Shared Patterns

- **Backward compat (D-05):** every new field `decodeIfPresent ?? default`, default reproduces current output; verify with legacy-JSON and default-dictionary tests.
- **Display names as pt-BR keys:** English literal in `displayName`, rendered with `Text(localizing:)`; add the string to Localizable.strings and (for lists) the test arguments.
- **Pure core, thin pumps:** decisions (crop detection, track selection, peak-fps drop rule, A/V align offset, gain) as pure `static` functions in Core with unit tests; pumps only wire them (see `GeometryPlanner`, `OutputSettingsBuilder`).
- **Fallback with note, not failure:** unsupported imports `notes.append(...)`; unsupported subtitle formats in `subtitlePump` return nil rather than failing the encode.
- **Quality bar (D-09):** files < 400 lines (EncodeSettings 270, PipelineFactory 292, HandBrakePresets 211 will exceed if extended: split first), functions < 50 lines, no force unwraps in new code (note `LocalizationTests` uses `try!` in test only), no `print`. Compat for macOS 26 APIs only via `Views/Components/Compat.swift`.
- **Theme tokens:** `Theme.panel/inspector/background/line/separator/text/muted/accent/accentLight/accentWash`, `.card(fill:radius:stroke:)` modifier (SettingsSection uses `.card(fill: Theme.panel, radius: 12)`).
