# Phase 03.1: HandBrake parity in the new layout — Context

**Discuss step:** skipped (`workflow.skip_discuss`). The decisions below come from the user's request and the parity inventory.

## User request (Portuguese speaker, paraphrased)

The app was first built to mirror HandBrake's settings (inventoried with REA). Then the window was redesigned (commit 08edcbf: dark three-column layout of sidebar, workspace and OutputInspector). "It looks like a lot of the original configuration disappeared… there's absolutely nothing of HandBrake anymore and everything was important. Only the visual was ugly."

Reality: the detailed tabs still exist (SettingsTabs.swift, DimensionsAudioTabs.swift, SubtitlesTab.swift, TrimTab.swift), but they're hidden in AdvancedSettingsSheet, which only opens from a small "Advanced Settings…" button, a right-click or ⌘E. The app also only ever covered part of HandBrake.

**Goal:** keep the NEW visual and bring the full HandBrake feature set back, visible.

## Spec

`HANDBRAKE-PARITY.md` in this folder is the spec. Each row has an ID (SUM-, DIM-, FIL-, VID-, AUD-, SUB-, CHP-, TAG-) and a status. Every **MF (this phase)** row must be implemented end-to-end, and every **PH** row must become visible inline. NF and deferred rows stay out of scope, and their reasons are documented.

## Locked decisions

- **D-01 Layout:** keep Theme.swift's dark theme, the sidebar, the workspace and the drop zone. With exactly ONE video selected, the right column becomes a wider tabbed **Video Settings panel**: a tab bar with Summary · Dimensions · Filters · Video · Audio · Subtitles · Chapters · Tags, with the full per-video settings inline and no sheet. The inspector column widens (about 420–460 pt) while a single video is selected. With several videos or none selected, the right column keeps the simplified "Output Settings" apply-to-all inspector, plus a visible hint/button: "Select one video to see all its settings". Trim & Preview stays reachable as a section of the Summary tab (or its own tab if it fits).
- **D-02 Advanced sheet:** may remain as a ⌘E shortcut that opens the same tab content in a large window, or be removed. The inline panel is the primary path.
- **D-03 Localisation:** every new label exists in EN (the source key) and pt-BR (`Sources/HyperVideoConverter/Resources/pt-BR.lproj/Localizable.strings`). `LocalizationTests` must pass.
- **D-04 Compat:** the deployment target is macOS 15. Any macOS 26-only API goes through `Views/Components/Compat.swift` helpers.
- **D-05 Model compatibility:** new `EncodeSettings` fields are optional or defaulted and decoded with `decodeIfPresent`. Their defaults reproduce today's output exactly, so old `queue.json` and presets load and encode the same.
- **D-06 Per-video vs preset:** per-video-only data (custom crop, trim, burn-in, chapter title edits, per-track lists bound to the source's track indexes, tags title) is reset by `presetSettings` and kept by `adopting` and `copyingAll` like trim/crop today. Generic choices (selection behaviour, languages, auto passthru, filters, framerate mode, profile…) travel with presets.
- **D-07 Engine:** all processing uses AVFoundation, VideoToolbox, Core Image or AudioToolbox, with no third-party code. Filters run in FrameFilter/FilterCompositor. Audio gain runs as a PCM sample transform in the audio pump. Framerate mode uses `sourceTrackIDForFrameTiming` plus a peak limiter. Tags are writer metadata, with MKV tags through MatroskaWriter where it already writes metadata.
- **D-08 Preset import:** `HandBrakePresets` maps every key listed in the parity doc's "Phase scope §6". NF keys add an import note instead of failing.
- **D-09 Quality bar:** tests first (Swift Testing), files under 400 lines, functions under 50 lines, no force unwraps, no `print`. Build and test with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build` / `swift test`.
- **D-10 Screenshots:** at the end, capture each tab of the running app (only the app window, `screencapture -l <windowid>`) into this phase folder.

## Out of scope

NF rows (WebM, iPod, detelecine, deblock, x264/x265/AV1 encoders, tunes, AC-3/MP3/Opus/FLAC encoding, Dolby matrix mixdowns, DRC, foreign audio search, bitmap subtitle burn), plus the deferred rows: custom size/PAR, multi-pass, color range, SRT charset.
