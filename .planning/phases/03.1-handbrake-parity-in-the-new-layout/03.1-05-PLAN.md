<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source audio tracks → reader/writer | Untrusted codec IDs, channel counts and sample rates |
| Settings from presets/queue → writer dictionaries | Gain, sample rate and bitrate may be out of range |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03.1-13 | DoS (crash) | audioPump writer input | mitigate | `writer.canApply(outputSettings:forMediaType:)` before creating the input, one retry without bitrate, else TranscodeError.cannotConfigure |
| T-03.1-14 | Tampering | AudioGain | mitigate | Gain clamped to ±20 dB, samples clamped to [-1, 1]; a failed transform returns the original buffer |
| T-03.1-15 | DoS | AudioGain.apply buffer math | mitigate | Sizes come from CMBlockBufferGetDataLength / sample count; no unchecked pointer arithmetic; Float32 interleaved format is what audioReaderPCM requests |
| T-03.1-16 | Spoofing | Passthru of unknown codecs | mitigate | Auto Passthru only copies codecs in PassthruCodec and in the container's accepted list, then confirms with writer.canAdd |
</threat_model>
