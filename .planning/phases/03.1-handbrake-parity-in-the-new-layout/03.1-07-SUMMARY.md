## Notes
- The chapter pump now uses `chapterOptions.writesMarkers(keepMetadata:)` and `Chapter.renamed` before clipping. MKV picks up renamed titles through the intermediate movie, with no remuxer change.
- `WriterMetadata.items` merges the user's tags over the source metadata. A source item with the same identifier or common key as a tag the user filled in is dropped. Only the user's tags are written when keepMetadata is off (T-03.1-22).
- `MatroskaMetadata` reads common and full metadata and adds ACTOR, DIRECTOR, COMMENT, GENRE and SYNOPSIS SimpleTags.
- `ChapterCSV` rejects input over 1 MB, throws a translated error on malformed lines, and handles BOM, CRLF, doubled quotes and `\,`.
- iTunes identifiers all read back in MP4 (verified by test), so no row was switched to QuickTime identifiers.
