## Fixed Issues

### CR-01: Summary tab's Quality Profile and size estimate act on the inspector targets
**Commit:** 7d4516d
**Applied fix:** Added a per-video API in the new file `Stores/AppModel+SourceProfile.swift`:
- `profile(of:)`
- `applyProfile(_:to:)`, which leaves the other videos and the draft alone
- `sizeEstimate(for:)`

`SummarySettingsTab` now takes `sourceID`. `EstimateCard` takes an optional estimate, and nil keeps the inspector behaviour. Tests: `PerVideoProfileTests`.

### CR-02: Chapter title field trims and resets on every keystroke
**Commit:** 54961a3
**Applied fix:** New `CommittingTextField`, a `@State` `TextDraft` with `@FocusState`. It commits on Return, on focus loss and on disappear, then shows the normalized value. Chapter titles use it. `SettingsTabContent` now applies `.id(source.id)`, so a draft or other tab state never moves to another video. Tests: `TextDraftTests`.

### CR-03: Languages fields re-format every keystroke
**Commit:** d3e842f
**Applied fix:** The audio and subtitle Languages fields use `CommittingTextField`. `LanguageList.parse` runs only on commit.

### WR-01: StatusBanner literals are never localized
**Commit:** caa61a3
**Applied fix:** The Dimensions and Filters banners pass `String(localized:)`. Documented that `StatusBanner` shows its text verbatim.

### WR-02: Before → After ignores the explicit track lists and language filters
**Commit:** 4c747f7
**Applied fix:** New `Stores/OutputTrackSummary.swift` mirrors the core planners:
- `keptSubtitleTrackCount(info:)` handles the explicit list (include and forced-only), languages, container support, burn-in and the first-track rule.
- `explicitAudioEncodings(info:)` returns the explicit list's encodings.

The summary describes a single explicit track's own encoding. Added the missing pt-BR "%lld tracks". Tests: `BeforeAfterSummaryTests`.

### WR-03: ForEach over the index-based audio track bindings can crash on removal
**Commit:** 6c7a632
**Applied fix:** Each card gets an id-based binding, through the new `EncodeSettings.updatingAudioTrack(_:)`. A late write to a removed track does nothing. Test: `updatingAudioTrackByIDIgnoresRemovedTracks`.

### WR-04: Crop Detect runs an unstructured Task
**Commit:** 145d303
**Status:** fixed: requires human verification (view state, no unit test)
**Applied fix:**
- Detect bumps a `detectRun` nonce that is part of the `.task(id:)`, so SwiftUI cancels the old run.
- Each run clears `detectedCrop` first.
- `isDetecting` is reset when the mode stops detecting.
- The result is applied only if the run wasn't cancelled and `info.url` still matches.
- The `.id(source.id)` from CR-02 also resets this state when the video changes.

### WR-05: Two confirmation dialogs share one `confirmingApplyToAll` flag
**Commit:** 6f8f824
**Status:** fixed: requires human verification (UI)
**Applied fix:** New shared `Views/Panel/ApplyToAllButton.swift` with a view-local `@State` flag, used by the panel and the Advanced sheet. Removed `UIState.confirmingApplyToAll`.

### WR-06: Export failures are reported under "Chapters not imported"
**Commit:** 4fd350c
**Applied fix:** `ChapterFileProblem` (`.import` or `.export`) picks the alert title. Added "Chapters not exported" in pt-BR. Test: `ChapterFileTests`.

### WR-07: "Apply to All" help and confirmation text understate what each video keeps
**Commit:** 004ff0b
**Applied fix:** Both strings now list the track lists, chapter names and title too. The pt-BR entries are updated. `UXLogicTests` checks the new wording.

### WR-08: Applying a preset resets encoder Speed
**Commit:** eec71e3
**Applied fix:** `keepingAdvanced` keeps `videoOptions.speed` when the template leaves it at the default. A new test uses `Mirror` to make sure every `VideoEncoderOptions` field is covered.

### WR-09: Explicit audio track lists silently override profile and inspector audio changes
**Commit:** aecfaa6
**Applied fix:** New `retuningAudioTracks()`. Applying a profile, adopting a preset and the inspector's "Keep original audio" toggle now set the encoder and bitrate of every explicit track. Each track keeps its mixdown, sample rate, gain and name. The Audio tab shows a note when an explicit list is active, with pt-BR.

The existing `adoptingKeepsPerVideoData` test now expects the retuned encodings: the list is kept, its encoder and bitrate follow the preset. Test: `profilesAndPresetsRetuneExplicitAudioTracks`.

### WR-10: Chapter rows combine an editable TextField into one accessibility element
**Commit:** 327dfa6
**Applied fix:** Rows use `.accessibilityElement(children: .contain)`. Each field is labelled "Chapter N title", with pt-BR.

### IN-01: CSV decoding fallback is dead code and mis-decodes UTF-16
**Commit:** cf777c7 (shared with IN-02)
**Applied fix:** `ChapterEditing.decodeCSV`: a BOM selects UTF-16, otherwise UTF-8 (a UTF-8 BOM is stripped), then Windows-1252. Tests in `ChapterFileTests`.

### IN-02: Size guard trusts a missing `fileSize`
**Commit:** cf777c7 (shared with IN-01)
**Applied fix:** `ChapterEditing.readCSV` reads at most `sizeLimit + 1` bytes with `FileHandle` and throws `.tooLarge` past the limit. It no longer depends on `fileSizeKey`.
**Core dependency:** `ChapterCSV.sizeLimit` is `internal` in HyperVideoCore. The app therefore keeps its own `ChapterEditing.sizeLimit`, documented as mirroring the core value. To have one shared constant, the core would need to make `ChapterCSV.sizeLimit` public.

### IN-03: Video profile/level normalization lives in a view `onChange`
**Commit:** 51c3b20
**Applied fix:** Added `normalizingEncoderOptions()` and `normalizingEncoderOptions(after:)` in the app target. They are used by:
- `choosing(codec:)`, which now drives the Video tab picker
- `applyingProfile`
- `adopting`, only when the codec actually changes, so existing stored profiles and levels are kept

The view `onChange` was removed. Test: `choosingACodecNormalizesProfileAndLevel`.

### IN-06: Menu shortcut builds a Character from a multi-digit string
**Commit:** b67912f
**Applied fix:** `SettingsTab.shortcutDigit(at:)` returns nil from the tenth tab on, and the menu uses the optional `keyboardShortcut`. Test in `PanelSelectionTests`.

### IN-07: Panel "Save as Preset" saves `inspectorSettings`
**Commit:** 5e72fcd
**Applied fix:** `AppModel.saveAsPreset(name:from:)` saves `source.settings` and sets the preset only on that video. The alert text is now "Saves this video's output settings as a reusable preset.", with pt-BR.

### IN-08: Switching Quality mode discards the previous value
**Commit:** 89c9521
**Applied fix:** `RateControlMemory` defines the named defaults `defaultQuality` and `defaultBitrateKbps` and remembers the last value of each mode. `QualitySection` keeps it in `@State`. Tests: `RateControlMemoryTests`.

### IN-09: Unlocalized pieces in track labels
**Commit:** 2395071
**Applied fix:** `AudioTrackCard.label` localizes `channelDescription` and shows "Unknown language" (pt-BR "Idioma desconhecido") instead of "und". Test: `AudioTrackLabelTests`.

### IN-10: Hard-coded sample date
**Commit:** fbb03e5
**Applied fix:** The Release Date prompt is `String(localized: "YYYY-MM-DD")`, which is "AAAA-MM-DD" in pt-BR. As instructed, the `-InitialSettingsTab` hook was left unchanged.
