# Phase 03.1.2.1: AI video upscale — Summary

**Done:** 2026-10-23 · engine chosen by the user: Real-ESRGAN through Upscayl (same as HyperImage).

## What it does
- Third mode in the toolbar: Convert | Compress | **AI Upscale** (⌘3).
- Panel: **Result preview** first (resolution before → after, file size before → after with a +N% badge and bars, time on this Mac), then AI model (Fast·Recommended / Animation & Art·Slow / Standard·Very slow / High Fidelity·Very slow), Enlargement 2×/3×/4× with "Limit to 4K" (on), File weight Light/Balanced/High + codec HEVC/H.264.
- Each row shows "→ 2560 × 1440 · ≈ 4.8 MB" in this mode; the Convert box says "Upscale N Videos".
- Jobs go through the normal queue (progress ring, time left, cancel, History, notifications).

## Keeping the file size viable
- The upscaled video is encoded at an **average bitrate** = width × height × fps × bits-per-pixel (HEVC 0.035 / 0.055 / 0.09; H.264 ×1.6), so the size is predictable. Audio is copied as is.
- Measured: 6 s 720p clip → 1440p HEVC Balanced: predicted ≈ 4.8 MB, real 4.62 MB (−4%). Growth +140–150% for a 2× upscale (4× the pixels).
- "Limit to 4K" is on by default.

## Speed (Apple M4, 720p → 1440p)
- Fast (lite) 1.1 s/frame (~33 min per minute of 30 fps video); Animation & Art 6.2 s; Standard/High Fidelity ~20 s. The time estimate uses these rates; the queue refines it while running.

## Engine
- `HyperVideoCore/Upscale`: `UpscaleSettings` (lenient Codable, stored in `EncodeSettings.upscale`), `UpscalePlan` (size, bitrate, bytes, time), `UpscaleBackend` (bundle or Vendor/Upscayl in debug), `UpscaylRunner` (process, cancel, progress by counting output frames), `FrameFiles` (byte-exact PNG round trip), `VideoUpscaler` (batches of 48 frames → upscayl → AVAssetWriter at the plan's bitrate with the source's colour tags → passthrough mux with the source audio).
- `Scripts/fetch-upscayl.sh` (pinned + SHA-256, copied from HyperImage); `Scripts/build-app.sh` bundles `upscayl-bin`, the four redistributable models and the AGPL licence. `Vendor/` is git-ignored.

## Bugs found while testing
- Colour shift (magenta → purple): Core Image colour-managed the frames and the output had no colour tags. Fixed with untouched PNG bytes and the source's tags (BT.709 for untagged HD). Test `keepsTheSourceColours`.
- "Fast · Fast" tag duplication; "0.0×" speed for slow jobs (now two decimals below 0.1×).

## Not covered / limits
- Subtitles, chapters and the other tabs' settings aren't applied when upscaling (stated in the panel).
- AI Upscale needs the bundled backend; builds without it show a banner and disable the button.
