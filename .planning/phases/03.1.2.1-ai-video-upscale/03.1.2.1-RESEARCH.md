# AI video upscale — research

**Date:** 2026-10-23 · **Goal:** an "AI Upscale" mode next to Convert | Compress (⌘3), like HyperImage's.

## Options

### A. Apple VideoToolbox Super Resolution (recommended default)
- `VTFrameProcessor` + `VTSuperResolutionScalerConfiguration` / `VTSuperResolutionScalerParameters`, macOS 26+ (`VTFrameProcessor` itself exists from 15.4). Apple pitches it for high-quality video editing (WWDC25 session 300); `VTLowLatencySuperResolutionScaler` is the real-time variant.
- ML models are downloaded by the system: check `configurationModelStatus`, call `downloadConfigurationModel` with the user aware of it, before `startSession`.
- Frames go in presentation order (`sequential` submission mode is fastest); seeking uses `random`, which resets caches.
- Fits the existing engine: decode with AVAssetReader → `processWithParameters` per frame → AVAssetWriter (HEVC/H.264/ProRes), audio/subtitles/chapters passed through as today.
- No license or bundled binaries. macOS 15 users don't get this path (show the mode disabled with a note).

### B. Real-ESRGAN via Upscayl's `upscayl-bin` (quality / anime option)
- Already integrated in HyperImage (`scripts/fetch-upscayl.sh`, pinned SHA-256, AGPL-3.0 run as a separate process, license shipped in `Contents/Resources/Licenses/`; only redistributable models).
- For video: extract frames (AVAssetReader → PNG in a work folder), run `upscayl-bin` over the folder, re-encode with AVAssetWriter at the source frame rate and copy the original audio. `realesr-animevideov3` is the video-tuned model.
- Slow (each frame is a full image upscale) and needs disk for frames; good for short clips, anime and archival footage. Works on macOS 15.
- Reference projects: Video2X (Real-ESRGAN/Real-CUGAN/RIFE via ncnn-Vulkan; no macOS release), realesrgan-ncnn-py (BSD-3, macOS ARM), Frame (Real-ESRGAN for video on Metal).

## Proposed shape
1. Mode "AI Upscale" in the toolbar picker; settings panel: engine (Apple · fast / Real-ESRGAN · max quality), scale 2×/3×/4× (limited by engine), model (Real-ESRGAN), output codec; estimate of time and size.
2. Engine protocol in HyperVideoCore with the VideoToolbox implementation first, Real-ESRGAN second (sharing HyperImage's fetch script).
3. Progress per frame, cancel, disk-space check (frames path), tests with the generated clips.
